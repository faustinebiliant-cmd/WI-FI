Why not import oswagolink-config.rsc

It is a copy of your router. Line 44 gives the new router your tunnel address 10.20.0.2, so two routers would fight over it.
Line 7 has the old router’s MAC address (admin-mac).
Lines 94 to 97 are your four test vouchers.
Line 25 turns on USB file sharing to the LAN.
It doesn’t hold the WireGuard private key or the passwords, and it has no login page file. Each router needs its own key, anyway.
Never copy the .backup file to a client router either. It clones the private key, and two routers with one key break each other’s tunnel.

#!/bin/bash
set -e
NAME="$1"; TIP="$2"; KEY="$3"
if [ -z "$NAME" ] || [ -z "$TIP" ] || [ -z "$KEY" ]; then
  echo "Usage: ./add-peer.sh CLIENT_NAME TUNNEL_IP ROUTER_PUBLIC_KEY"; exit 1

printf '\n# Client: %s\n[Peer]\nPublicKey = %s\nAllowedIPs = %s/32\n' "$NAME" "$KEY" "$TIP" | sudo tee -a /etc/wireguard/wg0.conf > /dev/null
echo "Added. Checking in 20 seconds..."
sleep 20
sudo wg show wg0 | grep -A4 "$KEY" || true
ping -c 3 "$TIP" || true
nc -vz -w 5 "$TIP" 8728 || true
ADDPEER
