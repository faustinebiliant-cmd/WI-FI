I am building Oswagolink, a multi-tenant hotspot billing SaaS for hotels and guest houses in Tanzania. The business model is voucher-based: guests buy a paper code at reception, enter it on a captive portal, and get WiFi for a set duration and speed.

## 3. ARCHITECTURE & SECURITY RULES
- 3 Frontends (React + Vite): portal, tenant-panel, platform-panel.
- 1 Backend (Node.js/Express): Port 5001.
- Database Driver: pg (Raw SQL). NO SUPABASE COMMANDS allowed.
- Router Adapter: services/routers/routerFactory.js returns MockRouter.js (dev) or MikroTikRouter.js (production). Currently set to ROUTER_MODE=mock.
- Security Rules: JWT_SECRET and ADMIN_JWT_SECRET are 32+ chars and strictly different. Router passwords are encrypted using AES-256. tenant_id is ALWAYS extracted from the JWT middleware.
- Timezone: All timestamps are handled in EAT (Africa/Dar_es_Salaam, UTC+3). Backend calculates EAT ranges and sends _eat formatted strings to the frontend.
- Router Paths: Vite base paths are set to /portal/, /tenant/, and /platform/. React Router basenames match these paths.
- CORS: The VPS .env ALLOWED_ORIGINS must include https://oswagolink.co.tz and https://www.oswagolink.co.tz.

## 4. THE XCOPY RULE (CRITICAL FOR FRONTEND)
Vite crashes if you import from outside its folder. We keep master UI files in frontend/shared/src/ and copy them into each app.
Every time we change a file in frontend/shared, run this in the root terminal:
xcopy frontend\shared\src\styles frontend\tenant-panel\src\shared\styles /E /I /Y
xcopy frontend\shared\src\components frontend\tenant-panel\src\shared\components /E /I /Y
xcopy frontend\shared\src\styles frontend\platform-panel\src\shared\styles /E /I /Y
xcopy frontend\shared\src\components frontend\platform-panel\src\shared\components /E /I /Y
Never edit files directly inside frontend/[app]/src/shared.

## 6. AUTOMATED SESSION CLEANER (NEW)
- We created a background service: `backend/services/sessionCleaner.js`.
- It runs every 60 seconds via `server.js`.
- It checks the `vouchers` table for any voucher where `expires_at < NOW()`.
- If found, it calls the router adapter to kick the user, updates the session's `ended_at` time, and sets the voucher status to `expired`.
- This prevents guests from getting free internet after their time runs out.
